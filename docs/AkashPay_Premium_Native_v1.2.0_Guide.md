# AkashPay Premium Native v1.2.0

## Product scope

This release keeps the core payment-monitoring behavior unchanged while upgrading the presentation layer to a production-style native Android experience. The APK does not embed the WebView.

## Premium UI changes

- Supplied `Neo.ttf` is packaged as the app font and applied to the connection screen and native dashboard.
- Official AkashPay logo is used in the permission screen and dashboard header.
- Dark navy/cyan luxury palette with gradient screen background, rounded cards, outlined controls, and animated primary actions.
- First-open premium permission explanation appears before Android permission prompts.
- The connection screen explains why SMS and notification access are needed and automatically starts device connection after permissions are granted.
- Returning users receive the same permission explanation if required permissions were later revoked.
- Dashboard includes Client ID/API key identity card with **Copy Client ID** and **Copy API key** controls.
- Advanced native navigation includes Sync now, Gateway numbers, SMS logs, and Orders.
- Sync button has a controlled pulse animation; connection and payment states are visible in the dashboard.

## Core logic preserved

- Only bKash and Nagad payment confirmation SMS messages are accepted.
- Unrelated messages are ignored locally.
- Accepted SMS messages continue to use the Cloudflare Worker upload and local retry queue.
- Background service, Telegram-linked status checks, payment notifications, and Cloudflare D1 storage remain unchanged.
- Client ID and API key are still generated by the server and stored in private Android preferences.

## Permission sequence

1. Premium AkashPay explanation dialog.
2. Android SMS and background-related permission prompt.
3. Android notification permission prompt on Android 13+.
4. Automatic POST to `https://akashpay-bot.axura.workers.dev/v1/public/logs/device-connect`.
5. Client ID/API key are saved and the native dashboard opens.

## Build details

- Version: v1.2.0
- Package: `com.payment.com`
- WebView classes: removed from the APK and manifest
- Font asset: `app/src/main/res/font/neo.ttf`
- Official logo asset: `app/src/main/res/drawable/akashpay_logo.png`
- Release signature: APK Signature Scheme v2 and v3 verified

## Cloudflare endpoint

```text
https://akashpay-bot.axura.workers.dev
```

The Android app contains no Firebase service-account credential, Telegram bot token, or Cloudflare API token.
